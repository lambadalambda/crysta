Experimental semantic preview — reference-qualified walking; doorway timing simplified; no original CPU

This is a bounded canvas preview, not a playable full game. Ordinary direction reuse and open/solid corners are supported. Rapid same-direction double taps trigger an unsupported dash error. Type16 and flagged cells are unsupported — use Reset after an error. No combat, sprites or audio. The background is static BG1 only, without BG2, animation, windows or scene effects.

Canvas is required for the preview.

Cyan box = player position, not an original sprite. Bottom center marks the feet.

Arrow keys / WASD, one direction at a time. Press Resume first. Release before changing direction. Escape pauses. Touch and hold a cardinal button; sliding outside releases it.

Doorway demonstration

Resets first, then sends 56 Left + 24 Down steps to the handoff, followed by 35 neutral transition steps, then pauses. Live controls are ignored during the sequence.

These are logical host steps, not reference-video timing. The client sends at most one step at a time, at up to 60 Hz; a slow connection slows the preview without a catch-up queue.

  • Transition input is neutral; held input is discarded at handoff.
  • Errors pause input. Reset to try a fresh supported path.
  • Blur or a hidden tab pauses and releases all controls. Resume explicitly when you return.
All simulation belongs to the Rust host. This page only sends input and draws its state over /map.bmp.
