Experimental semantic preview — reference-qualified walking; doorway timing simplified; no original CPU

This is a bounded canvas preview, not a playable full game. Choose New Game, then Resume to explore the supported house paths. This semantic start uses the default name and skips the intro and room-entry dialogue; it does not play the original opening. Ordinary walking, partial furniture and passive flagged walls are supported; rapid same-direction double taps trigger an unsupported dash error. The six fresh house rooms are connected. Open the wooden door, talk to the northern room’s resident, then leave south through the house’s exterior gate. Only a small outdoor landing is supported; cellar and further town progression remain outside scope. Ark uses ROM-derived standing/walking sprites. All nine residents and the bedroom table object use frozen source-setup poses. Source-setup occupancy is solid; NPC movement and other residents’ interactions are not simulated. The northern resident’s Japanese dialogue and explicit choices are supported. No combat or audio. Only the static first background (hardware BG2) is shown; other layers, windows and scene effects are omitted. Idle gestures and doorway animation use ordinary standing by policy.

Canvas is required for the preview.

ROM-derived Ark, nine frozen residents and the table object, with natural colors and high-background occlusion. Doorway pacing remains simplified.

ROM-derived Japanese text; simplified dialogue presentation.

Arrow keys / WASD, one direction at a time. Press Resume first. Release before changing direction. Escape pauses. Space/Enter or Interact opens the wooden door or talks to the qualified resident; release movement first. Face Up against the door in the upper part of the western middle room, then continue north and face Up toward the resident. Use Continue for pages, or explicitly choose an option / Cancel. Tab and Enter work on choice buttons. Interaction pauses the preview; Resume to walk again. Touch and hold a cardinal button; sliding outside releases it.

Checkpoint doorway demo

Checkpoint Reset and this demo use the saved checkpoint, not New Game. The demo resets to that checkpoint first, then sends 56 Left + 24 Down steps to the handoff, followed by 35 neutral transition steps, then pauses. Live controls are ignored during the sequence.

These are logical host steps, not reference-video timing. The client sends at most one step at a time, at up to 60 Hz; a slow connection slows the preview without a catch-up queue.

  • Transition input is neutral; held input is discarded at handoff.
  • Errors pause input. Choose New Game or Checkpoint Reset to try again.
  • Blur or a hidden tab pauses and releases all controls. Resume explicitly when you return.
All simulation belongs to the Rust host. This page only sends input and draws its state over /map.bmp.
